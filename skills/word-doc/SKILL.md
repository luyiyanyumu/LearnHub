你要交付的不是一段"可以自己复制到 Word 里"的正文，而是**一个能点开就下载的 .docx 文件**。
做法：用工具 `create_word_document` 生成，然后把返回的下载链接放到回答最后。

## 一、铁律：交付物是文件，不是正文

1. 用户说「导出/生成 Word/文档/报告」时，**必须调用 `create_word_document`**。只把 Markdown 正文贴回对话里 = 任务没完成（用户还得自己复制、粘贴、另存、调格式）。
2. 生成的文档**必须**在回答**最后一行**给出下载链接，形如：

   ```markdown
   📄 [Java 并发笔记.docx](/api/files/12/download)
   ```

   链接文本用返回里的 `file_name`，地址用 `download_url`（照抄 `markdown_link` 最省事）。
3. 链接前用两三句说明**这份文档里有什么**（结构、覆盖范围、总字数级别）。不要把全文再贴一遍 —— 正文已经在文件里了。
4. 不许说"已生成"却不给链接，也不许给一个自己拼的链接（比如拿标题去猜 URL）。链接只能来自工具返回。

## 二、内容从哪来

1. **以工作台里的既有内容为准**：先用 `get_note` / `search_knowledge` / `get_file` 取到原文，再生成文档。
   **不要凭记忆重写用户的笔记** —— 用户要的是"把他记的东西变成文件"，不是"让模型再写一遍"。
2. 用户说「把这篇文章/这份资料导出」时，读那份资料（`get_file`，长文用 `offset` 续读）后生成。
3. 用户只给了个题目（"写份 XX 的方案"）时，先在心里组织结构再生成；能引用工作台已有内容就引用，并在文档里保留出处标记。
4. 多份来源合成一份时，**保留各自标题层级**，并在开头写一段"本文档由以下内容整理"。

## 三、Markdown 怎么写才渲染得好看

工具会把 Markdown 渲染成 Word 样式，支持的范围与写法：

| 写法 | 效果 |
| --- | --- |
| `# 一级标题` ~ `#### 四级标题` | Word 标题（字号递减、加粗）。**文档只有一个 `#`**，各章用 `##` |
| 普通段落 | 正文段落。**段落之间空一行**，否则会被并成一段 |
| `- 项` / `1. 项` | 项目符号 / 编号；行首缩进 2 空格 = 二级 |
| `> 引用` | 斜体缩进引用（用于注意事项、原话摘录） |
| ` ```java ... ``` ` | 等宽代码块（保留缩进；标注语言不影响渲染，但便于将来复制） |
| `\| 表头 \| ... \|` + `\| --- \|` | 表格，**第一行当表头加粗**；列数保持一致 |
| `**加粗**`、`*斜体*`、`` `代码` `` | 行内样式 |

写作要求：

1. **别写目录**（"目录"这种手写清单在 Word 里没有页码，是负担）。
2. **别用 `#### 以下` 的更深层级**（不支持，会退化成普通段落），需要更细就改用加粗小标题或列表。
3. 表格列数别超过 5 列（A4 宽度会挤）；单元格内容尽量短。
4. 不认识的语法（图片、HTML 标签、脚注）会**当普通文本原样输出**，所以别指望它们有效果 —— 需要插图时改用文字说明。
5. `markdown` 参数上限约 20000 字。内容更长就拆成两份文档（如"上/下"），或先精简。

## 四、参数怎么填

| 参数 | 说明 |
| --- | --- |
| `title` | 文档标题，同时用作文件名。**必填**，写清楚主题（如「Java 并发笔记」） |
| `markdown` | 正文。**必填** |
| `summary` | 一句话说明，进检索用（如"Java 并发：线程池参数与常见坑"）。建议填 |
| `category_name` | 放进哪个分类，不存在会自动创建；不确定就留空 |

## 五、交付前自检（三条，缺任一就是没做完）

1. 工具返回里 `ok` 是不是 `true`？返回 `ok: false` 时把 `error` 如实转述，**不要**假装成功。
2. 回答最后一行是不是那个下载链接？（复制粘贴返回的 `markdown_link` 即可）
3. 有没有把全文又贴一遍？（贴了就是错，删掉）

## 六、生成之后

1. 文档已进资料库，**能被检索命中**（正文会被抽取）。用户之后问"我上次导出的那份文档讲了啥"时，用 `search_knowledge` 找得到。
2. 用户说"再改改那份文档"时：先 `search_knowledge` 或 `list_files` 找到它、`get_file` 读出内容，改完**重新生成一份**（不要试图原地编辑 —— 工具只负责生成）。
3. 用户要 Excel / PPT 时如实说明目前只支持 Word，可以用 Markdown 表格给出数据，或在 Word 里用表格承载。
