# LearnHub 0.1.5

本版增加后台知识库自动维护和全社区星系图，并改进长笔记生成、网页获取及本地启动流程。

- 知识库自动维护默认开启：后台按资料及配置变化更新索引、Wiki、图谱和社区，保存进度并在失败后退避重试。面板显示各阶段的实际状态和具体错误，关闭页面后仍继续运行。
- 全部社区进入同一张白底二维星系图，取消分页；支持拖拽、缩放、社区展开及返回时保留视角。使用空间索引、视野裁剪、远景聚合与分级标签控制大图开销。
- 长笔记通过子智能体分节生成后合并，改进上下文预算、公式完整性和工具调用过程中的记忆保留。
- 改进资料库列表布局、代码块预览和公式转换；本地启动器启动时会重新启动后端，便于加载源码更新。
- 网页获取支持可选的隔离 Scrapling 浏览器服务，用于动态页面；默认部署仍使用 HTTP 获取。启用方法见[网页获取说明](../web-fetching.md)。
- 新增本地知识参数模型的实验性源码与界面，自动训练默认关闭，需单独部署模型服务。其拒答可靠性尚未达到要求，不宜作为唯一知识入口，见[功能说明](../knowledge-model.md)。

升级包含 Flyway V4–V6 迁移，新增笔记目录及本地模型任务结构，并修正图谱归一化名称的精确比较。迁移保留已有资料、笔记和图谱；后台自动维护会按需调用已配置的模型，可在知识库维护面板关闭。

首次安装：

```sh
npx @luyiyanyumu/learnhub@0.1.5 start
```

更新已有启动器管理的实例：

```sh
npx @luyiyanyumu/learnhub@0.1.5 update
```

更新命令会先备份数据库、资料、技能和配置，再执行迁移与健康检查；自定义实例须沿用原来的 `--home`。前后端镜像均提供 Linux amd64 / arm64。
