# LearnHub 0.1.6

本版更新知识分块与检索上下文、智能体笔记协作、分屏布局，并提供独立的 Windows 图形启动器。

- 知识分块按标题、段落和完整句子组织正文，保护代码围栏、多行公式及 Markdown/HTML 表格；重叠不再截断受保护结构。Word 检索文本保留标题和表格结构。
- 长资料可选语义切割，默认仍为结构切割。分块正文、序号、小节和来源指纹持久化到数据库；检索复用一致边界，排除过期向量，并在预算内补齐相关邻块和具有明确层级的父节原文。语义切割会增加构建耗时，当前合成评测不足以支持默认开启，见[分块说明](../knowledge-chunking.md)。
- 多章节笔记补写先规划完整范围，再内部并发生成、统一校验并提供一张确认卡片；融入可定位多个章节。片段失败、截断或版本冲突时停止写入；当前草稿在笔记操作前自动保存，失败或切换笔记时保留草稿。
- 智能体显示更详细的执行进度，并按当前任务生成受限操作选项；历史会话可恢复相关选项。生成结果不完整时不提供直接写入笔记的操作。
- 界面适应窄屏、低高度窗口与浏览器缩放：工具条、筛选、设置和弹窗操作换行或滚动，资料分页避开悬浮按钮。分屏保留常驻大纲，更窄时通过顶栏“大纲”按钮打开主题抽屉；长标题换行，调整窗口不重置开合选择，保留编辑器、草稿和撤销历史。
- 提供 [Windows 启动器 1.1.0](https://github.com/luyiyanyumu/LearnHub/releases/tag/launcher-v1.1.0)：检查服务、启动和停止、构建并应用源码、日志与脱敏诊断、源码版本检查，以及启动器独立更新。它替代原 Windows 启停批处理入口，使用说明与源码构建方法见[启动器文档](../../launcher/README.md)。
- 更新项目文档、合成评测工具和演示发布素材；示例不包含本机知识库、配置、密钥或数据库备份。

## 安装与升级

```sh
npx @luyiyanyumu/learnhub@0.1.6 start
```

更新已有启动器管理的实例：

```sh
npx @luyiyanyumu/learnhub@0.1.6 update
```

`update` 会先备份数据库、资料、技能和配置，再执行迁移与健康检查；自定义实例继续使用原来的 `--home`。前后端镜像均提供 Linux amd64 / arm64。

本版包含 Flyway **V7**：将较小的 `kb_chunk.chunk_text` 列扩展为 `MEDIUMTEXT`，保留已有正文、向量和来源状态。切块参数变化后需要重建索引才会采用新的边界；旧 Word 文件若需新的标题与表格抽取结构，应重新抽取正文，仅重建向量不会重新解析文件。

源码部署用户更新代码后，仍需重新构建并应用前后端镜像；单纯重启旧容器不会加载新代码。Windows EXE 的更新与应用服务更新互相独立。
