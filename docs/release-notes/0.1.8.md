# LearnHub 0.1.8

- 资料库新增结构化 Markdown 阅读、源码查看和按块核对。可以复制或下载指定版本的 Markdown，或导出包含原图与来源定位的资源包。
- PDF 和图片可接入本地 PP-StructureV3 服务逐页识别文字、表格和公式。长文档支持分批继续。人工核对后可将合格的扫描内容发布到检索，原件和已可靠识别的内容继续保留。
- Word、Excel 和 PPT 的抽取保留可识别的原生结构。阅读器可以追溯原图、公式和分页信息，区分印刷页码与原件页序号。
- 知识图谱支持切换 3D 视图。界面新增萤火虫主题，并改进资料浏览、知识检索与智能体进度显示。

[结构化 Markdown 与来源定位](https://github.com/luyiyanyumu/LearnHub/blob/v0.1.8/docs/document-markdown.md) · [本地扫描与 OCR 部署](https://github.com/luyiyanyumu/LearnHub/blob/v0.1.8/docs/document-ocr.md)

## 安装与升级

npm 包 `@luyiyanyumu/learnhub@0.1.8` 使用同版本的前后端容器镜像，支持 Linux amd64 和 arm64。现有实例可使用 npm 启动器更新。高精度扫描服务需单独部署与配置。

[安装与升级步骤](https://github.com/luyiyanyumu/LearnHub/blob/v0.1.8/docs/releases.md#用户安装与更新)
